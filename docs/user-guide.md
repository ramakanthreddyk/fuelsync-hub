## Getting Started

### System Requirements

- **Web Browser**: Chrome, Firefox, Safari, or Edge (latest versions)
- **Internet Connection**: Required for OCR processing and cloud storage
- **Device**: Desktop, tablet, or mobile phone
- **Account**: FuelSync account with appropriate plan

### First Time Setup

1. **Access FuelSync**: Navigate to your FuelSync application URL
2. **Login**: Use your provided credentials or contact your administrator
3. **Explore Dashboard**: Familiarize yourself with the main interface
4. **Check Plan**: Verify your subscription plan and available features

### User Roles

**Super Admin**
- Complete system access

- Plan administration

**Pump Owner/Manager**
- Station operations management
- Employee oversight

**Employee**

## Upload Receipts

### Supported Formats
- **Image Types**: JPG, JPEG, PNG
- **File Size**: Maximum 10MB per file
- **Quality**: Clear, well-lit images work best

### Upload Process

1. **Navigate to Upload Page**
   - Click "Upload" in the sidebar menu
   - Or use the quick action button on dashboard

2. **Select Receipt Image**
   - Click "Choose File" or drag and drop
   - Ensure image is clear and readable
   - Receipt should be fully visible

3. **Upload and Process**
   - Click "Upload Receipt"
   - Watch progress bar during upload
   - Wait for OCR processing to complete

4. **Review Results**
   - Check extracted data for accuracy
   - Edit manually if needed (Basic/Premium plans)
   - Confirm fuel type and amount

### Upload Limits by Plan
- **Free Plan**: 4 uploads per day
- **Basic Plan**: 10 uploads per day
- **Premium Plan**: Unlimited uploads

### Tips for Better OCR Results
- **Good Lighting**: Avoid shadows and glare
- **Flat Surface**: Keep receipt flat and straight
- **Complete Receipt**: Include all relevant information
- **High Resolution**: Use device's highest quality camera setting

## Sales Tracking

### View Sales Data

1. **Access Sales Page**: Click "Sales" in sidebar menu
2. **Filter Options**:
   - Date range selection
   - Fuel type filter
   - Pump selection
   - Shift filtering

3. **Sales Information Displayed**:
   - Transaction date and time
   - Pump and nozzle used
   - Fuel type (Petrol/Diesel)
   - Quantity in litres
   - Price per litre
   - Total amount
   - Shift (morning/afternoon/night)

### Daily Summary

- **Revenue Totals**: Sum of all transactions
- **Volume Sold**: Total litres dispensed
- **Transaction Count**: Number of sales
- **Fuel Type Breakdown**: Separate totals for petrol and diesel
- **Shift Analysis**: Performance by time period

### Trends and Analytics

Available on Basic and Premium plans:
- **7-day trends**: Weekly performance overview
- **30-day trends**: Monthly performance analysis
- **Comparative data**: Period-over-period comparisons
- **Charts and graphs**: Visual representation of data

## Fuel Price Management

*Available on Basic and Premium plans*

### View Current Prices

1. **Access Prices Page**: Click "Prices" in sidebar menu
2. **Current Rates Display**:
   - Petrol price per litre
   - Diesel price per litre
   - Last updated date and time
   - Updated by information

### Update Prices

1. **Select Fuel Type**: Choose petrol or diesel
2. **Enter New Price**: Input price per litre
3. **Confirm Update**: Click "Save Price"
4. **Verification**: System confirms successful update

### Price Management Tips
- **Regular Updates**: Monitor market rates frequently
- **Competitive Pricing**: Stay aware of local competition
- **Documentation**: Keep records of price changes
- **Timing**: Consider optimal times for price adjustments

## Pump Management

*Available on Basic and Premium plans*

### Pump Overview

View all pumps with:
- **Pump Name/ID**: Unique identifier
- **Current Status**: Active, Inactive, or Maintenance
- **Nozzle Configuration**: 4 nozzles per pump
- **Fuel Types**: Assigned to each nozzle
- **Today's Sales**: Revenue generated today
- **Last Maintenance**: Date of most recent service

### Pump Status Management

1. **Access Pumps Page**: Click "Pumps" in sidebar menu
2. **Status Options**:
   - **Active**: Pump is operational
   - **Inactive**: Pump is offline
   - **Maintenance**: Pump is being serviced

3. **Update Status**:
   - Click on pump status button
   - Select new status from dropdown
   - Confirm change

### Nozzle Configuration

1. **Inline Editing**: Click on nozzle fuel type
2. **Select Fuel Type**: Choose Petrol or Diesel
3. **Save Changes**: Confirm selection
4. **Status Update**: Enable or disable nozzles

### Maintenance Tracking
- **Maintenance Dates**: Record when service occurred
- **Service History**: Track pump maintenance over time
- **Performance Impact**: Monitor sales before/after maintenance

## Troubleshooting

### Common Issues

**OCR Processing Problems**
- **Symptom**: Poor text recognition from receipts
- **Solutions**:
  - Ensure good lighting when photographing
  - Keep receipt flat and straight
  - Use higher resolution camera settings
  - Manually edit extracted data if needed

**Upload Failures**
- **Symptom**: Files not uploading successfully
- **Solutions**:
  - Check internet connection
  - Verify file size (max 10MB)
  - Ensure supported file format (JPG, PNG)
  - Clear browser cache and try again

**Login Issues**
- **Symptom**: Cannot access account
- **Solutions**:
  - Verify email and password
  - Check caps lock status
  - Request password reset
  - Contact administrator for account status

**Data Sync Problems**
- **Symptom**: Information not updating
- **Solutions**:
  - Refresh browser page
  - Check internet connection
  - Clear browser cache
  - Contact support if persists

**Performance Issues**
- **Symptom**: Slow loading or responses
- **Solutions**:
  - Check internet speed
  - Close unnecessary browser tabs
  - Clear browser cache
  - Try different browser
